Documentation

1. Comments

Comments are ignored by the compiler. AniKode has three simplified styles:

~ Standard Single Line comment
\ Documentation Single Line comment
--
Multi-line block comment
--
#3#
say.out("A")
say.out("B")
say.out("C")
Disables the next 3 statements. Resilient to edits inside!

2. Variables & Casting

Declare variables and convert strings to numbers using casting functions:

let x = 10
set y to 25
z = x + y
let val = int(say.in("Value: "))
let rawStr = str(100)
let decimal = float("3.14")
let empty = null

3. Inputs & Outputs

Display messages or request synchronous key input from the user:

say.out("User", name, "is", age, "years old.")
let name = say.in("Your name? ")

4. Loops

Iterate safely. Loops are protected from infinite-loop glitches!

loop i from 1 to 5 {
  say.out(i)
}
(Range Loop - Auto counts up/down)
each fruit in fruits {
  say.out(fruit)
}
(Collection Loop - JS Array iteration)

5. Functions & Recursion

Define reusable code and recurse safely without repeating names:

fn openDoll(size) {
  if size == 1 {
    return "Prize!"
  }
  return recurse(size - 1)
}
